# 项目描述

    这是一个使用Unity开发的Rogue式VN项目，仅为个人练习。

# 开发环境

    Unity 2022.3.62f1c1
    Visual Studio 2022

# 文件目录

```text
Assets/
├─ Scenes/             主菜单、游戏及示例场景
├─ Scripts/            游戏 C# 代码
│  ├─ Audio/            音频播放与管理
│  ├─ Bootstrap/        场景启动与系统绑定
│  ├─ Display/          显示系统
│  ├─ InputSystem/      输入命令与输入状态
│  ├─ MainMenu/         主菜单、画廊、设置和存档面板
│  ├─ Rogue/            地图、节点、剧情步骤、存档和状态机
│  ├─ Setting/          设置配置与持久化
│  └─ Utility/          事件总线、资源加载等通用代码
├─ AssetBundles/       地图配置与预制体；Audio/Sprites 为本地资源
├─ Resources/          运行时资源；TestSprites 为本地测试素材
├─ StreamingAssets/    随项目提供的 AssetBundle 文件
├─ TextMesh Pro/       TextMesh Pro 资源
└─ Tree_Textures/      纹理资源
Packages/              Unity 包配置
ProjectSettings/       Unity 项目及构建设置
```


# 打开方式

用 Unity Hub 打开项目根目录，然后在 Unity Editor 中打开 `Assets/Scenes/MainMenu.unity` 并运行。

`Assets/Resources/TestSprites/`、`Assets/AssetBundles/Audio/` 和 `Assets/AssetBundles/Sprites/` 是当前工作区未纳入 Git 的资源目录。如果场景引用了这些素材，其他检出环境可能出现资源引用缺失。

# 已实现的内容

- 主菜单、游戏场景、画廊和设置界面的基础流程，以及场景切换和返回主菜单的入口。
- Rogue 地图配置加载与构建、楼层和节点推进、节点内步骤及选择分支。
- 对话、角色、背景、BGM 等剧情组件的播放代码，以及音频、显示和输入系统。
- 手动存档面板、JSON 存档读写和存档槽位展示；读档目前存在阻断问题，见下文。
- 设置数据的读取、修改和保存。

# 已知缺陷

- 读档按地图 ID 查询的缓存目前没有写入路径，存档地图无法正常加载；即使地图加载成功，当前节点及完成状态也尚未恢复，无法完整续玩。
- 问题记录提到：终点节点切换地图时，旧的进入节点输入可能被缓存，导致镜头回移；当前版本仍需复验。
- 部分加载器、播放器和状态基类仍含 `NotImplementedException` 占位实现；调用相关路径时可能中断。
- 所有业务脚本位于默认 Assembly-CSharp，没有通过 asmdef 建立编译边界。
- 游戏业务代码缺少自动化测试，部分边界条件只能依赖手动验证。
